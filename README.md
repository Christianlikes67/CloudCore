# CloudCore OS

CloudCore OS is a browser-based desktop environment built with **HTML, CSS, and JavaScript**. It recreates the feel of a modern operating system directly inside the browser, featuring a window-based interface, application management, personalization, and persistent local storage.

The project is focused on creating a lightweight and expandable WebOS while demonstrating what can be achieved using only standard web technologies.

---

## ✨ Features

### Desktop Environment

* Modern desktop interface
* Draggable and focusable application windows
* Responsive layout
* Glassmorphism-inspired UI
* Taskbar and desktop icons
* Window management system

### Built-in Applications

* 🌐 Browser
* 📝 Notes (Auto Save)
* 📖 Journal
* 🧮 Calculator
* ⚙️ Settings

### Personalization

* Wallpaper selection
* Custom wallpaper uploads
* Persistent user preferences
* Desktop customization

### Application Management

* Built-in App Store
* Install new applications
* Uninstall installed applications
* Dynamic application loading

### Storage

* Local Storage support
* Automatically saves:

* Notes
* Journal entries
* Wallpapers
* Installed apps
* User settings

---

## 🛠 Built With

* HTML5
* CSS3
* JavaScript (Vanilla)

No frameworks or external libraries are required.

---

## 💡 How It Works

CloudCore OS runs entirely inside the browser.

Every application opens inside its own movable desktop window, providing an operating system-like experience without requiring any installation.

User data is stored locally using the browser's Local Storage API, allowing applications, wallpapers, notes, and settings to persist between sessions.
